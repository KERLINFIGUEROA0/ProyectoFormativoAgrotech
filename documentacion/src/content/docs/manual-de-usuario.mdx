# Manual de Usuario

## Inicio de Sesión

[Iniciar Sesión](/)

Para iniciar sesión en la aplicación AgroTech, sigue estos pasos:

1. Abre la página principal de la aplicación.
2. Ingresa tu nombre de usuario y contraseña en los campos correspondientes.
3. Haz clic en el botón "Iniciar Sesión".
4. Si las credenciales son correctas, serás redirigido al dashboard principal.

## Recuperación de Contraseña

[Recuperar Contraseña](/recuperar)

Si has olvidado tu contraseña, puedes recuperarla de la siguiente manera:

1. En la página de inicio de sesión, haz clic en el enlace "Olvidé mi contraseña".
2. Ingresa tu dirección de correo electrónico asociada a tu cuenta.
3. Haz clic en "Enviar".
4. Revisa tu correo electrónico para un enlace de restablecimiento.
5. Haz clic en el enlace y establece una nueva contraseña.

## Módulo de Actividades

[Gestionar Actividades](/gestion-actividades)

El módulo de actividades permite gestionar tareas agrícolas. Para crear una nueva actividad:

1. Ve a la página de gestión de actividades.
2. Haz clic en "Crear Nueva Actividad".
3. Completa los detalles como nombre, descripción, fecha, materiales requeridos, etc.
4. Asigna la actividad a un usuario si es necesario.
5. Guarda la actividad.

También puedes ver el cronograma en [Cronograma de Actividades](/cronograma).

## Módulo de Cultivos

[Gestionar Cultivos](/gestion-cultivos)

Para gestionar cultivos:

1. Accede a la gestión de cultivos.
2. Crea un nuevo cultivo ingresando nombre, tipo, etc.
3. Gestiona lotes asociados en [Gestionar Lotes](/gestion-lotes).
4. Ve la producción en la página específica de cada cultivo.
5. Revisa la trazabilidad en [Trazabilidad de Cultivo](/cultivos/:id/trazabilidad).

## Módulo de Usuarios

[Gestionar Usuarios](/gestion-usuarios)

El módulo de usuarios permite administrar cuentas de usuario. Para crear un nuevo usuario:

1. Ve a la página de gestión de usuarios.
2. Haz clic en "Crear Nuevo Usuario".
3. Completa los detalles como nombre, correo electrónico, rol, etc.
4. Asigna permisos según sea necesario.
5. Guarda el usuario.

Puedes editar o eliminar usuarios existentes desde la lista de usuarios.

## Módulo de Finanzas

[Gestionar Finanzas](/gestion-finanzas)

Para gestionar finanzas y gastos de producción:

1. Accede a la gestión de finanzas.
2. Registra nuevos gastos en [Gastos de Producción](/gastos-produccion).
3. Gestiona ventas en [Ventas](/ventas).
4. Revisa reportes financieros y balances.

## Módulo de Materiales

[Gestionar Materiales](/gestion-materiales)

El módulo de materiales permite controlar inventarios. Para agregar un nuevo material:

1. Ve a la página de gestión de materiales.
2. Haz clic en "Crear Nuevo Material".
3. Ingresa detalles como nombre, tipo, cantidad, unidad de medida, etc.
4. Asigna a lotes o actividades según corresponda.
5. Guarda el material.

## Módulo de Lotes

[Gestionar Lotes](/gestion-lotes)

Para gestionar lotes de cultivo:

1. Accede a la gestión de lotes.
2. Crea un nuevo lote especificando cultivo, ubicación, tamaño, etc.
3. Actualiza el estado del lote en [Actualizar Estado de Lote](/lotes/:id/estado).
4. Monitorea el progreso y producción asociada.

## Módulo de Sensores

[Gestionar Sensores](/gestion-sensores)

El módulo de sensores permite monitorear condiciones ambientales. Para configurar un sensor:

1. Ve a la página de gestión de sensores.
2. Agrega un nuevo sensor con detalles como tipo, ubicación, configuración MQTT.
3. Revisa la información en tiempo real en [Información de Sensores](/sensores).
4. Configura alertas y notificaciones según umbrales definidos.
