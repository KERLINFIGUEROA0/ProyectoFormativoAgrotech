# Módulo WebSocket

## Funcionalidades Avanzadas

- **Comunicación Bidireccional**: Conexión en tiempo real con clientes
- **Eventos del Sistema**: Emisión de actualizaciones automáticas
- **Integración con MQTT**: Retransmisión de datos de sensores
- **Gestión de Conexiones**: Control de sesiones activas

## Flujo de Trabajo

1. **Conexión**: Cliente establece WebSocket con servidor
2. **Suscripción**: Cliente se registra para eventos específicos
3. **Recepción**: Servidor emite datos en tiempo real
4. **Actualización**: Cliente actualiza interfaz automáticamente

## Integración con Otros Módulos

- **MQTT**: Retransmisión de lecturas de sensores
- **Notifications**: Sistema de notificaciones push
- **Cultivos**: Actualización de datos en tiempo real
- **Información Sensor**: Streaming de datos IoT
